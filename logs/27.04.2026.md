### 3. Frontend Projesi Kurulumu (client/)
- **Vite + React** projesi `client/` klasörüne kuruldu
- **firebase** ve **react-router-dom** paketleri yüklendi
- **Port sabitlendi:** `localhost:5173` (`vite.config.js` → `strictPort: true`)

#### Oluşturulan Klasör Yapısı:
```
client/
├── .env                          ← API key'ler (GitHub'a gitmiyor!)
├── .gitignore                    ← .env, node_modules, dist hariç
├── vite.config.js                ← Sabit port: 5173
└── src/
    ├── firebase/
    │   └── config.js             ← Firebase Auth + Firestore bağlantısı
    ├── context/
    │   └── AuthContext.jsx       ← Giriş/Kayıt/Çıkış + Firestore profil sync
    ├── components/
    │   ├── Sidebar.jsx           ← NavLink aktif menü + Logout
    │   └── ProtectedRoute.jsx    ← Giriş yapılmadan erişim engeli
    ├── layouts/
    │   └── VolunteerLayout.jsx   ← Sidebar + Topbar iskeleti
    ├── pages/
    │   ├── Login.jsx             ← Split tasarım (Sol panel + Sağ form)
    │   ├── Register.jsx          ← Gönüllü kayıt formu
    │   ├── Dashboard.jsx         ← Impact & Stats (Grafik + Sentiment)
    │   ├── BookManagement.jsx    ← Ses yükleme (Cloudinary) + Firestore
    │   └── RecordingStudio.jsx   ← Canlı mikrofon kaydı (MediaRecorder API)
    ├── App.jsx                   ← BrowserRouter + tüm rotalar
    └── index.css                 ← Global CSS tasarım sistemi
```
